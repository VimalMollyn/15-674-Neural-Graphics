# Gaussian Splatting

P1-P5: code in `a2.py`. To run, `uv run a2.py`. This runs the 2D gaussian splatting and saves the outputs to `images`.

P6-9: code in `a2_3D.py`. To run, `uv run a2_3D.py`. This prints the PSNRs and saves the renders and the final gaussian splat to `images`. 

`view_gaussians.py` is a gaussian splat renderer created with the help of Claude Code in order to render the novel views and observer the scene interactively.
